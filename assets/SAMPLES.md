# Markdown sample fixtures

All sample documents are in [samples/](samples/).
Their images stay in `assets/`, with paths relative to each document.

The default profiler uses six paired fixtures:

| Size | Text only | With images |
| --- | --- | --- |
| Small | `SAMPLE-SMALL-TEXT.md` | `SAMPLE-SMALL-IMAGES.md` |
| Mid | `SAMPLE-MID-TEXT.md` | `SAMPLE-MID-IMAGES.md` |
| Huge | `SAMPLE-HUGE-TEXT.md` | `SAMPLE-HUGE-IMAGES.md` |

Every pair shares the same prose. TEXT has no raster images, SVG, or Mermaid.
IMAGES adds two, five, or 100 distinct PNG/JPEG files, plus a local SVG and a Mermaid flowchart.
The image editions contain no deliberately missing assets. Existing syntax/error fixtures below remain unchanged.
Run `python3 tools/scripts/generate-profile-samples.py` to regenerate these six editions from the original fixtures without changing image bytes.
`sample-vector.svg` is a project-generated observation pipeline used by all three image editions.
It exercises local SVG independently from Mermaid's generated SVG.

`SAMPLE-SMALL.md` is a short text-only document with regular and bold text.
It includes headings, paragraphs, lists, a quotation, links, and a table.
It has no images, diagrams, italic text, or code blocks and needs only the bundled fonts.

`SAMPLE.md` contains five distinct local images: two JPEGs and three PNGs.
It also contains one deliberately missing image to test alternative text.
The document stays near 22 KB of text, including wide tables. Its image assets total about 170 KiB.
`SAMPLE-SMALL.md`, `SAMPLE.md`, and `SAMPLE-HUGE.md` use only characters covered by the bundled Latin fonts, including decoded entities.
`SAMPLE-EXTENDED.md` contains the non-Latin scripts, additional symbols, and emoji used to exercise system font fallback.

`SAMPLE-HUGE.md` is a fictional field operations handbook with 100 station reports.
Each report has different data, tables, prose, code, and its own image reference.
The text is about 1.9 MB, approximately 100 times the compact sample.
Its 100 distinct images comprise 60 PNGs and 40 JPEGs, totaling about 4.7 MiB.
No chapter reuses another chapter's image path or image bytes.

The synthetic fixtures include charts, processing diagrams, and textured spatial
surveys. Sizes range from 480 × 320 to 1440 × 810 pixels. PNG variants include
RGB, palette, and transparency. JPEG variants include color, grayscale,
baseline, and progressive encoding. The measurements are fictional.
These files test image decoding and scaling; they are not scientific evidence.

Run `python3 tools/scripts/generate-samples.py` to rebuild the synthetic assets and handbook.
Regeneration needs Python, Pillow, and NumPy. Normal builds and fixture validation
do not need Pillow or NumPy. Asset encoding can change across Pillow versions.
Run `python3 tests/samples.py` to check image uniqueness, formats, and references.
Profiles record the text and local image workload for each document.
These test assets are not embedded in the executable or installed by the packages.

## NASA image

`sample-earthrise.jpg` is the 1024 × 576 JPEG from
[Earthrise 2.0, NASA Scientific Visualization Studio](https://svs.gsfc.nasa.gov/10951/).
Credit: **NASA's Goddard Space Flight Center**. Visualization: Ernie Wright (USRA).
The file is unmodified and is not regenerated by the script.

Source: <https://svs.gsfc.nasa.gov/vis/a010000/a010900/a010951/earthrise.2121_1024x576.jpg>

NASA media usage guidance: <https://www.nasa.gov/nasa-brand-center/images-and-media/>.
The sample uses the image for illustration and testing; NASA does not endorse MDF.

Other sample graphics are project-generated test data. `sample-landscape.png`
remains an older fixture and is not referenced by the current sample documents.
