## Reading notes

Markdown turns plain text into a readable document. Headings divide the page,
paragraphs explain each topic, and **bold phrases** draw attention to key points.
Resize the window to check line wrapping and use the minimap to move through
the document.

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Integer vitae purus
at nibh finibus posuere. Donec sed lectus sit amet justo feugiat facilisis.
Vestibulum ante ipsum primis in faucibus orci luctus et ultrices posuere
cubilia curae. Praesent blandit, risus vitae varius pretium, nibh erat
fermentum tortor, sed malesuada neque justo quis erat.

> Keep related information together. A short quotation can contain
> **bold text** and continue onto another line.

## Lists

### Unordered list

- Open a local document.
- Read the **important notes** first.
- Check the layout at different window sizes.
  - Make the window narrow.
  - Increase the text size.
  - Return to the default size.
- Follow a heading link to jump to another section.

### Ordered list

1. Review the document title and contents.
2. Read the paragraphs and the table below.
3. Compare the light and dark appearance.
4. Scroll to the end and return to the beginning.

### Checklist

- [x] Regular and bold text.
- [x] Headings, paragraphs, and lists.
- [x] A table and a block quotation.
- [ ] Try a narrow window.
